# Archived reports

These are dated snapshots kept for reference; they describe the game as it was when each was written, not as it is now. They use the legacy 60-stage numbering — `scripts/core/CampaignRenumbering.cs` maps an old stage number to its current one in the 100-stage campaign.

- [COMBAT_BENCHMARK_60_STAGE.md](COMBAT_BENCHMARK_60_STAGE.md) — September benchmark sweeps of the 60-stage campaign.
- [DIRECT_PLAYTEST.md](DIRECT_PLAYTEST.md) — direct-input boss and late-game playtest observations.
- [EXPANDED_CAMPAIGN.md](EXPANDED_CAMPAIGN.md) — forward posts, supply caches, encounter areas and all-stage results on the old 2560-unit battlefield.
- [EXPANSIVE_EXPLORATION.md](EXPANSIVE_EXPLORATION.md) — the version 44 isometric zone maps, kept for save migration.
- [FUN_AND_PROGRESSION_UPDATE.md](FUN_AND_PROGRESSION_UPDATE.md) — 25 September reward and challenge changes.
- [PLAYER_FEEDBACK_UPDATE.md](PLAYER_FEEDBACK_UPDATE.md) — playtest update: starter squad, food, discovery, audio and account sign-in.
- [PROGRESSION_DESIGN.md](PROGRESSION_DESIGN.md) — 11 September progression analysis and an unapplied economy proposal.
- [progression/](progression/STAGE_MATRIX.md) — per-stage matrix and `audit.json` behind the progression analysis.
- [STAGE_LENGTH_REVIEW.md](STAGE_LENGTH_REVIEW.md) — review after the battlefield length was doubled.
- [UI_REVIEW.md](UI_REVIEW.md) — 6 September UI and code review.
