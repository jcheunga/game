# Crownroad — five roster model styles

Created 11 October 2026 with the built-in image generation tool.

Five concept sheets each show the same 16 representative roster entries in a 4 × 4 grid. These are visual references for choosing model art direction. Each sheet includes eight player units and eight hostile entries, including one boss.

| Set | Image | Visual direction |
| --- | --- | --- |
| 01 | [Low-poly](01-low-poly.png) | Faceted geometry, broad shapes, flat colors. |
| 02 | [Soft cartoon](02-soft-cartoon.png) | Smooth rounded bodies, large heads, friendly faces. |
| 03 | [Cel-shaded](03-cel-shaded.png) | Graphic silhouettes, dark outlines, crisp shadow bands. |
| 04 | [Clay miniatures](04-clay-miniatures.png) | Rounded handmade forms, matte clay texture. |
| 05 | [Papercraft](05-papercraft.png) | Folded cardstock shapes, angular layers and printed details. |

Player rows: Peasant, Spearman, Archer, Shield Knight; Cavalry Rider, Field Medic, Mage, Ballista Crew.

Enemy rows: Risen, Ghoul, Rot Hulk, Rustguard; Blight Caster, Bone Lancer, Plague Engine, Ashen Regent.

All sheets keep teal allied cloth and crimson enemy cloth, with consistent ordering and role cues. Some poses, proportions and equipment details vary with each interpretation. The existing game assets have not been replaced.

The final prompt for every set is in [prompts.md](prompts.md). The updated playable roster and melee design were used to select subjects; the theme bible supplied faction identity. The files were visually checked for all 16 entries, correct label order, complete figures, and distinct visual styles.
