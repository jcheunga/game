# Crownroad — five themed roster model sets

Created 11 October 2026 using the built-in image generation tool with project art references. Sets 06–10 are additional model concept directions anchored in the Crownroad medieval royal-caravan versus undead-siege theme.

Each sheet contains the same sixteen representative entries as sets 01–05: eight player units and eight enemies including the Ashen Regent boss.

| Set | Image | Direction |
| --- | --- | --- |
| 06 | [animated royal fantasy](06-animated-royal-fantasy.png) | Closest to the existing animated fantasy concepts; adult faces, sculpted shapes and teal-and-brass heraldry. |
| 07 | [road-worn realism](07-road-worn-realism.png) | More grounded proportions, practical kit and believable worn materials. |
| 08 | [gothic siege](08-gothic-siege.png) | Sharper armor silhouettes and a darker royal-versus-undead mood. |
| 09 | [painted kingdom](09-painted-kingdom.png) | Hand-painted surfaces and broad brush accents that echo the game’s illustrated world. |
| 10 | [heroic siege strategy](10-heroic-siege-strategy.png) | Broad adult silhouettes, thick equipment and stronger role cues for small battles. |

Player rows: Peasant, Spearman, Archer, Shield Knight; Cavalry Rider, Field Medic, Mage, Ballista Crew.

Enemy rows: Risen, Ghoul, Rot Hulk, Rustguard; Blight Caster, Bone Lancer, Plague Engine, Ashen Regent.

Shared identity: teal and ivory allied clothing; blue-black iron, worn steel, aged brass, oak and leather; crowned-lantern heraldry and amber shrine lights. Enemies use crimson and charcoal, weathered bone, gray-green skin and restrained green magic. All sheets were checked for sixteen roster entries, readable names, full model framing and theme continuity.

The base generation prompts and project references are in [prompts.md](prompts.md). The final style transformations for sets 07–10 are in [style-refinements.md](style-refinements.md). These are concept images; existing runtime game assets remain unchanged.
